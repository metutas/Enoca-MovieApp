Bu uygulama, Enoca Android Developer staj süreci kapsamında geliştirilmiştir. Temel odak noktam; modern Android kütüphanelerini kullanarak, sürdürülebilir ve temiz bir kod mimarisi (Clean Architecture prensipleri) sergilemektir.

🛠️ Neler Kullandım? (Tech Stack)
Projeyi geliştirirken sektörün kabul gördüğü modern araçları tercih ettim:

Jetpack Compose: Kullanıcı arayüzünü (UI) tamamen deklaratif bir yapıyla kurarak, performanslı ve esnek bir deneyim sağladım.

MVVM Mimari Deseni: Veri yönetimi ile arayüz katmanını birbirinden ayırarak kodun okunabilirliğini ve test edilebilirliğini artırdım.

Retrofit & GSON: TMDB API üzerinden gelen karmaşık verileri hızlı ve güvenilir bir şekilde modele dönüştürdüm.

Coil: Uygulama performansını düşürmeden, asenkron bir şekilde görsellerin yüklenmesini ve önbelleğe alınmasını (caching) yönettim.

Navigation Compose: Sayfalar arası geçişleri (Liste -> Detay) tip güvenliği gözeterek kurguladım.

✨ Öne Çıkan Detaylar
API Entegrasyonu: Gerçek zamanlı film verileri için The Movie Database (TMDB) altyapısı kullanılmıştır.

Clean Code: Değişken isimlendirmelerinden klasör yapısına kadar her noktada SOLID prensiplerini ve okunabilirliği ön planda tuttum.

Dinamik UI: API'den gelen veriye göre şekillenen, kullanıcıyı yormayan modern bir tasarım.

🚀 Çalıştırma Talimatları
Projeyi klonlayın: git clone https://github.com/metutas/Enoca-MovieApp.git

Android Studio'da projeyi açıp Gradle senkronizasyonunun tamamlanmasını bekleyin.

Önemli: Uygulamanın çalışması için geçerli bir TMDB API Key'e sahip olmanız gerekmektedir.

Cihazınızda (veya emülatörde) Run butonuna basın.
